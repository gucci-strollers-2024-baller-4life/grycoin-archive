# k=5 letter-class sweep, anchor mode (2026-10-31)

## What was run

The family is not combinatorial guesswork. The certified stage-one answer selects paragraphs by a
membership test on the first letter against a five-letter class (I,T,A,S,M) and marks the paragraphs
outside the class with first-letter-down / last-letter-up at the alphabetic token edges (proved by
the case diff in AUDIT_INDEXING §9). This sweep enumerates **every** C(26,5) class in exactly that
mode, on both certified bases.

- selector: paragraph's first letter **not** in the class -> marked
- mode: first alphabetic letter lowercased, last alphabetic letter uppercased
- bases: `wp_paras_br.json`, CRLF (`bd07e6ee`) and LF (`46a308c2`)
- indices: 0-7, 44, 76, 77
- guard: on. Every base rebuilt through `harness/corpus.py` with the certified digest asserted.

Dedupe is not bookkeeping: a class containing a letter that no paragraph starts with produces the
same text as the class without it, so 131,560 texts collapse to 55,792 distinct documents. The 21
present initials are `ABCDEFGHIKLMNOPRSTVWY`.

## Verdict

**Negative, and this time the negative has a mechanism behind it.** Stage one's rule, instantiated
across the whole class space on the certified bases, does not produce either escrow. What that means
precisely: if the chapter's payload is a marking operation of this shape, the sign class is not a
5-letter subset of the English alphabet applied uniformly to all 273 paragraphs.

Not yet covered by this pass: the inverse mode (inside the class, first-up/last-down), which is a
further ~614k derivations, and any family where the marking applies to a *subset of paragraphs*
selected by something other than a single letter class.
